# Frontend interface

These images document the V0.1 React workspace with fictional demonstration data. They are intended to make the repository easier to evaluate without exposing client, legal or personal information.

## Command Center

The operational dashboard surfaces critical deadlines, today's work, hearings, archive readiness, personal tasks, priority Matters, recent documents and team activity.

![Command Center](images/command-center.png)

## Matter workspace

The Matter detail is the product's central screen. The overview combines identity, status, priority, confidentiality, recent timeline entries, upcoming actions and shortcuts, with tabs for the remaining legal operations.

![Matter detail](images/matter-detail.png)

## Document Center

The document library shows category, immutable version number, original filename, size and client visibility, with controlled actions for download, version history and reversible deletion.

![Document Center](images/document-center.png)

## Client portal administration

Authorized users can review portal identities, last access, shared Matter count and revocation state. A separate form creates a 72-hour, single-use invitation so the client defines their own password.

![Client portal administration](images/client-portal-management.png)

The rendered interface is a development preview. Runtime behavior and accessibility remain covered by the validation strategy described in the root README and should receive broader browser automation before real use.
